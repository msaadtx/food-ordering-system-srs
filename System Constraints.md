# System Constraints

The following constraints affect the design and development of the system .

Budget: 
This is a student project, so the budget for hosting and third-party services is limited.

Location:
 Delivery is available only within the QAU Islamabad campus boundary. Off-campus delivery is not supported.

Internet:
 The system requires an active internet connection and does not work offline.

Payment: 
Online payment is limited to Pakistani platforms: 
Easypaisa,  JazzCash,  bank apps, and  domestic debit/credit cards. Cash on Delivery is also offered as a non-digital option.

Language: 
The primary language is English.
 Urdu is an optional display setting in the first version.

Hardware:
 Users need a smartphone or computer with a web browser.
keypad phones are not supported.

Time:
 The first version must be completed within the givenm timeline.
